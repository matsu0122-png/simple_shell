# Simple Shell in C

## 概要

本プロジェクトでは、C言語を用いてUnix風の簡易シェルを実装した。
コマンド実行に加え、パイプ処理、リダイレクション、バックグラウンド実行などの基本機能を備えている。

本シェルの実装を通して、プロセス生成やプロセス間通信などのOSの基本機構について理解を深めることを目的とした。

---

## 実装機能

### コマンド実行

```sh
ls
ls -l
```

---

### パイプ処理

```sh
ls | wc -l
ls | grep c | wc -l
```

複数のコマンドを接続し、標準出力を次のコマンドの標準入力へ渡す。

---

### リダイレクション

```sh
echo hello > a.txt
cat < a.txt
echo world >> a.txt
```

* `<` : 入力
* `>` : 出力（上書き）
* `>>` : 出力（追記）

---

### 連続リダイレクション

```sh
cat < input.txt > output.txt
grep hello < input.txt > result.txt
```

複数のリダイレクションを同時に扱うことが可能。

---

### バックグラウンド実行

```sh
sleep 5 &
```

コマンドをバックグラウンドで実行し、即座にプロンプトへ戻る。

---

### バックグラウンドプロセス回収

```text
[background pid=12345 done]
```

終了したプロセスは非同期で回収される。

---

### 組み込みコマンド

| コマンド        | 説明           |
| ----------- | ------------ |
| cd          | ディレクトリ移動     |
| pwd         | カレントディレクトリ表示 |
| exit / quit | シェル終了        |

---

### シグナル処理

* `Ctrl+C` を押してもシェルは終了しない
* 実行中の子プロセスのみ終了

## 実装のポイント

### プロセス生成

* `fork()` により子プロセスを生成
* `execvp()` によりコマンドを実行

### パイプ処理

* `pipe()` によるプロセス間通信
* `dup2()` により入出力を接続

### リダイレクション

* `open()` でファイルを開く
* `dup2()` により標準入出力を変更

### バックグラウンド処理

* `waitpid(..., WNOHANG)` を使用し非同期回収

---

## 制限事項

本シェルには以下の制限がある。

* クォート（"hello world"）未対応
* 環境変数展開（`$HOME`）未対応
* 条件付き実行（`&&`, `||`）未対応
* セミコロン（`;`）未対応
* 標準エラー出力（`2>`）未対応

本シェルでは、Unixシェルの基本機能を実装し、システムコール（fork, exec, pipe, dup2, waitpid）を実際に利用することで、OSの動作を理解することができた。
